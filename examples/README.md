# Examples

This folder is reserved for anonymized sample judge reports and a full end-to-end run (Prompt A → Prompt B → Prompt C → Prompt D), referenced from the main README.

No samples are published yet — reports produced by AIPA are, by construction, generated from a specific person's private chat history, so each example needs to be reviewed and stripped of anything identifying before it goes in here. Contributions of anonymized runs (in any of the three languages under `/prompts/`) are welcome via pull request.
